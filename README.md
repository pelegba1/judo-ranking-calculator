# מחשבון דירוג ג'ודו

אתר סטטי שמחשב ומציג תחזית של דירוג העולם של IJF (הפדרציה הבינלאומית לג'ודו): אפשר לראות את הדירוג הנוכחי, ולבדוק איך תוצאות עתידיות או נקודות שפוקעות ישפיעו על המיקום.

**האתר:** https://pelegba1.github.io/judo-ranking-calculator/

## מקור הנתונים

הנתונים נשלפים מ-data.ijf.org. זהו מקור לא רשמי, והחישובים באתר אינם רשמיים ועלולים לסטות מהדירוג של IJF.

## הרצה מקומית

דרוש Node 24 ומעלה.

```
npm install
npm run dev        # שרת פיתוח של האתר
npm run pipeline   # שליפת נתונים וחישוב מחדש (כותב ל-public/data ול-data-cache)
npm test           # הרצת הבדיקות
```

## עדכון אוטומטי

GitHub Action בשם `nightly` רץ כל לילה ב-05:00 שעון ישראל. הוא מריץ בדיקות, מריץ את ה-pipeline, מבצע commit לנתונים שהשתנו, בונה את האתר ומפרסם אותו ב-GitHub Pages. אם בדיקה, ה-pipeline או הבנייה נכשלים, שום דבר לא נשמר ולא מתפרסם.

להרצה ידנית: לשונית **Actions** בגיטהאב, בחירת **nightly**, ואז **Run workflow**.

## אימות

הדירוג המחושב הושווה לדירוג הרשמי של IJF. ב-2026-11-09 ההתאמה הייתה 97.95% בבוגרים, 98.86% בנוער (juniors) ו-99.47% בקדטים. פירוט ההבדלים ב-`docs/validation-notes.md`.
